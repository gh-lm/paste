Look

There is a button for this in the list itself, beside the cog. A dot on it means the browser is choosing.

Clicking a note

A click always copies the note to the clipboard. It can also drop the text straight into whatever box you had the cursor in.

Keyboard shortcuts

Four notes can be given a slot when you edit them. The matching keys then paste that note straight into whatever you are typing in, without opening anything. Four is all a browser allows an extension to arrive with.

Alt and a number is deliberately not used, because browsers keep that for jumping to a pinned tab and always win.
