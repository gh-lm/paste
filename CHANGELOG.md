# Changelog

Notable changes to Lightmorphic Paste. The extension and the website are
released separately: the extension goes to the Chrome Web Store, the website
goes live as soon as it is pushed.

## Extension

### 1.0.0 — 30 August 2026

First release. Published to the Chrome Web Store on 2 September 2026.

- Notes are kept as ordinary bookmarks in a folder of their own, so they travel
  between computers on the browser's own bookmark sync, with no account and no
  server
- Click a note to copy it, or turn on copy-and-paste so a click also drops it
  into the box you were typing in
- Notes group into tabs, and both notes and tabs are dragged into the order you
  want
- Four keyboard shortcuts, Ctrl+Shift+1 to Ctrl+Shift+4, paste straight into
  whatever you are typing in
- Right-click selected text to save it; right-click a text box to paste a note
- Search across every tab at once
- Follows the browser's light or dark setting, with a button to override it
- Twelve accent colours, or a colour of your own
- One-click import of notes left by another snippet extension, found by the
  shape of the bookmarks rather than by any folder name
- Backup to a file, and restore from one

The extension was called Pastemorphic until 30 August 2026. Installing this
over that version loses nothing: the folder is found by what is inside it,
both former folder names are still recognised, and notes saved by either
earlier version are still read.

## Website

### 6 September 2026

- The website is dark only. The extension still follows the browser and still
  has its switch; only the site lost one
- The Lightmorphic app menu is on every page, including the 404
- A footer in three parts: the project, the repository, and the legal details

### 2 September 2026

- Cookies, terms, accessibility and complaints pages added, so all five legal
  pages exist and are linked from every footer
- A real 404 page, rather than GitHub's own
- Every page's last-updated date is taken from the commit that last changed it
- A content security policy, carried in the page because GitHub Pages sets no
  headers
- The sixteen FAQ questions are real headings, so a screen reader can move
  between them
