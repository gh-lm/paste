Help

Everything Lightmorphic Paste does, in the order you are likely to need it.

01

Saving a line of text

There are two ways. Click the toolbar icon and press the round yellow button next to the name. That opens an empty note for you to type or paste into. Give it a name if you like; if you do not, the first few words become the name.

Or, on any web page, select some text, right-click it and choose Add to Lightmorphic Paste. It goes straight into the tab you had open last.

02

Copying and pasting

Click a note and its text is on your clipboard. Paste it wherever you like in the usual way.

Or have it typed for you. In Settings, turn on Clicking a note copies it and pastes it. After that, clicking drops the text straight into whatever box your cursor was in before you opened the list. Notes then read Copy and paste when you hover over them, as a reminder that the text is going somewhere.

Each note also has its own paste button on the right, which pastes whatever that setting says.

There is a third way that catches people by surprise, in a good way: right-click inside any text box on any page and your notes are listed in the menu. Pick one and it is typed in for you without the list ever opening.

03

Tabs

Notes are grouped into tabs, up to six of them, seven letters each. Those two numbers go together: seven letters makes a tab narrow enough that three fit across, and the strip is two rows deep, so every tab is always visible and nothing can be pushed out of sight.

  • The + button on the right makes a new one. It asks for the name first, so you never end up with several called "New tab".
  • The button beside it renames or deletes the tab you are on.
  • Drag a tab to move it. A line shows the gap it will drop into.
  • Two tabs cannot share a name.

Deleting a tab deletes the notes in it, so it asks twice: the bin turns into a tick, and only the tick deletes. The same is true everywhere in Lightmorphic Paste: nothing is ever deleted on one click.

04

Keyboard shortcuts

Four notes can hold a slot, and the matching keys paste that note straight into whatever you are typing in without opening anything:

  • Ctrl Shift 1 to Ctrl Shift 4

Give a note a slot while you are editing it. Four is not an arbitrary number: it is every shortcut a browser lets an extension arrive with.

You can change any of them from your browser's own shortcuts page, and there is a button in Settings that takes you straight there. Whatever you set is what the list shows. Lightmorphic Paste asks the browser rather than assuming.

Alt and a number is deliberately not used. Browsers keep that for jumping to a pinned tab and always win.

05

Bringing notes in, and taking them out

If you have used another snippet extension that also stored its notes as bookmarks, Settings will find them and offer to bring them across in one click. They are copied, not moved, so nothing of yours is removed. Running it twice is safe, because anything already there is skipped.

Settings also has Save a backup file and Restore from a file. A restore adds notes rather than replacing what is there. That backup file is also how you move notes between two different browsers, since bookmark sync only joins browsers of the same family.

06

Where your notes actually live

In a bookmark folder called Lightmorphic Paste, normally inside Other bookmarks. Settings shows you the exact path and has a Show me the folder button that opens your bookmark manager at the right place.

You can rename that folder or drag it anywhere you like. Lightmorphic Paste finds it by what is inside it, not by its name, so nothing breaks.

Uninstalling the extension leaves the notes behind, because they are bookmarks. Delete the folder and they are gone for good.
