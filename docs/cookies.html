Cookies

This site sets no cookies. Nothing about you is tracked here, and nothing is passed to anyone else.

What is not here

There is no analytics, no advertising, no social buttons, no embedded video, and no fonts loaded from anywhere else.

One thing does come from another address: the app menu behind the button of sixteen dots at the top right. It is served from apps.lightmorphic.com, which is Lightmorphic's own machine, not a third party's. It sets no cookies and reads none, it tracks nothing, and it draws itself in a sealed part of the page so it can neither read this site nor be read by it. Every other file the page needs comes from this site.

Nothing is stored either

The site keeps nothing in your browser at all. No cookies, no local storage, no session storage. Close the tab and there is no trace that you were here, because there never was one to leave.

The pages themselves run no JavaScript. The only script is the app menu described above, and it stores nothing either.

The extension

Lightmorphic Paste, the extension itself, is a separate thing from this website and also sets no cookies and makes no network requests. The privacy page covers what it stores and where.
