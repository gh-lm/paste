# Contributing

Thank you for taking an interest in Lightmorphic Paste. It really is appreciated.

The way this project is set up, the code is written and kept in one place by
Lightmorphic Ltd, so we can't take code changes from outside. That has nothing
to do with the quality of anyone's work. We just find it works best when we
hear what went wrong, and fix it ourselves.

So the most useful thing you can send is a description:

- **Something broken?** Open an issue and tell us what you did, what you
  expected, and what happened instead. The extension version and which browser
  you use help a great deal. A screenshot is welcome too.
- **An idea?** Tell us what you were trying to do and where Paste got in the
  way. You don't need to suggest how to fix it.
- **A security problem?** Please use private reporting rather than a public
  issue. [SECURITY.md](./SECURITY.md) explains how.

Lightmorphic Paste is GPL v3, so you are always free to fork it and take it in
your own direction.
